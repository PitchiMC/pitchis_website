Keep it Simple

Simple Lobby Command is a lightweight Minecraft plugin that does exactly what you need for a basic lobby system.


Set your lobby location with /setlobby and let your players return to it anytime with /lobby. No unnecessary features, no complicated setup.

Core Features

  • /lobby: Teleport to the configured lobby.
  • /setlobby: Set the current location as the lobby.
  • Lightweight: Does exactly what it needs to do.
  • Simple: No unnecessary features or bloat.

Commands & Permissions

Commands

  • /lobby - Teleport to the lobby.
  • /setlobby - Set the lobby location.

Permission

  • simplelobbycommand.setlobby - Allows the use of /setlobby.
